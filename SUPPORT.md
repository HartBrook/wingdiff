# Support

Wingdiff is pre-1.0, community-supported software.

- Use [GitHub Discussions](https://github.com/HartBrook/wingdiff/discussions)
  for setup help, questions, and ideas.
- Use [GitHub Issues](https://github.com/HartBrook/wingdiff/issues) for
  reproducible defects and accepted feature work.
- Use [private vulnerability reporting](https://github.com/HartBrook/wingdiff/security/advisories/new)
  for security concerns. Do not disclose vulnerabilities in issues or
  discussions.

When asking for help, include your operating system, Node.js version, Wingdiff
version or commit, the command you ran, and a redacted error. Do not post API
keys, private source, pull-request content, local database files, or launch
tokens.
